# EpicBowGun - Machine Gun Bow Plugin

A Minecraft plugin that transforms the bow into a machine gun, firing multiple arrows in rapid succession!

## Features

- 🏹 **Machine Gun Mode**: Fire up to 5 arrows with a single shot
- ⚡ **Rapid Fire**: Quick succession shots for maximum firepower
- 🎯 **Spread Effect**: Realistic spread pattern for machine gun feel
- 🔧 **Easy Toggle**: Use `/machinegun` command to enable/disable
- 📦 **Spigot Compatible**: Works with Minecraft 1.20+

## Installation

1. Build the plugin using Maven: `mvn clean package`
2. Drop the JAR file into your `plugins/` directory
3. Restart your server
4. Use `/machinegun` to toggle the feature

## Commands

- `/machinegun` - Toggle machine gun bow mode
- `/mg` - Alias for machine gun
- `/bowgun` - Alias for machine gun

## Configuration

Edit `plugins/EpicBowGun/config.yml` to customize:

- Fire rate (ticks between shots)
- Number of arrows per burst
- Arrow spread pattern

## Requirements

- Minecraft Server 1.20+
- Spigot/Paper server
- Java 11+
